IMPORTANT:

Do NOT blindly copy any reference website.

Use the references only for design inspiration, information architecture, visual hierarchy, spacing, interaction patterns, and overall quality.

1. https://www.avaya.com/en/

## 1. Understand the existing CoreIP business first

CoreIP is a technology company working around:

- Unified Communications

- Telecom Solutions

- Security Solutions

- Networking Solutions

- Hosting Solutions

- IPPBX / VoIP

- Video Conferencing

- NMS / Network Management

- Complaint Management System

- IP Phones

- Servers

- Media Gateways

- UCX / Cloud communication solutions

The current website already contains real products, solutions, industries, partners, projects and company information.

PRESERVE the important existing business information and product names.

Do not invent fake products, fake statistics, fake certifications, fake customers, fake awards or unsupported claims.

If existing content is grammatically weak, improve the wording while keeping the meaning accurate and professional.

- Premium

- Modern

- Trustworthy

- Clean

# 3. Visual language

Use a strong modern technology aesthetic.

Suggested visual direction:

- Deep navy / dark blue as the primary brand foundation

- White and very light neutral sections for contrast

- Subtle blue/cyan gradients where appropriate

- Professional accent color

- Large typography

- Strong whitespace

- Rounded cards, but not excessively rounded

- Thin borders

- Soft shadows

- Subtle glass/gradient effects only where they genuinely improve the design

- High-quality technology imagery

- Abstract network/communication visual elements

- Subtle animated background elements

Do NOT make every section dark.

Use a mixture of:

- Dark premium sections

- Clean white sections

- Light grey sections

- Accent sections

The website should have a strong visual rhythm.
